🛠️ التطبيق العملي: تقسيم شبكة 192.168.1.0/24 إلى 4 شبكات فرعية معزولة منطقياً.
📖 المصدر الموصى به: تمارين Subnetting.org ودليل CCNA Basics.
مستوى العمق: Level 3 (Practical)

صلتها بالأمن السيبراني: أغلب الهجمات السيبرانية تنفذ بواسطة استغلال ثغرات أو نفقية في DNS أو HTTP.

🛠️ التطبيق العملي: اعتراض حركة مرور عبر Burp Suite والاطلاع على Header الخاص بطلبات HTTP.

صلتها بالأمن السيبراني: مهارة لا غنى عنها في SOC و DFIR للتحقيق الجنائي واكتشاف الثغرات التسريبية.

🛠️ التطبيق العملي: فتح ملف PCAP والتحري عن كلمة سر مرسلة بالنص الصريح عبر HTTP غير مشفر.

إدارة الأنظمة والـ Active Directory (SysAdmin & Operating Systems)

التمكن الكامل من التعامل مع بيئات Linux و Windows والمصادقة المؤسسية.

⏱️ الجهد الزمني المقدر: 90 - 110 ساعة عمل فعلي
🗓️ 10س/أسبوع: 9-11 أسبوع | 15س/أسبوع: 6 أسابيع | 20س/أسبوع: 4 أسابيع
🎓 طالب CS: التجاوز المباشر لأوامر Linux العادية، التركيز فقط على Active Directory والاذونات.
📚 المنهج الدراسي التفصيلي للمرحلة
مستوى العمق: Level 3 (Practical)

ماذا تتعلم: أوامرBash، إدارة الأذونات (Chmod, Chown, SUID/SGID)، والخدمات (Systemd/Cron).

صلتها بالأمن السيبراني: 90% من السيرفرات وأدوات الأمن تعمل على Linux، ورفع الصلاحيات يعتمد على الثغرات الأمنية بها.

🛠️ التطبيق العملي: إعداد خادم Web على Ubuntu وإعطاء أذونات محددة للمستخدم لمنع الاختراق.
📖 المصدر الموصى به: Linux Journey أو كورس OverTheWire Bandit.
مستوى العمق: Level 3 (Practical)

ماذا تتعلم: السجلات (Registry)، العمليات (Processes/Services)، وسجلات الأحداث (Security Event Logs).

صلتها بالأمن السيبراني: تتبع النشاط المشبوه للمخترقين واكتشاف ملفات التشغيل التلقائي الملوثة.

🛠️ التطبيق العملي: استخدام Sysinternals (Procmon/Autoruns) لفحص تشغيل العمليات بالخلفية.
📖 المصدر الموصى به: أدوات Sysinternals وسلسلة Windows Forensics.
مستوى العمق: Level 3 (Practical - جوهري)

ماذا تتعلم: Domain Controller, OUs, Group Policy (GPO)، وبروتوكولات Kerberos و NTLM.

صلتها بالأمن السيبراني: 95% من بيئات الشركات تعتمد على AD وهو الهدف الرئيسي المفضل للـ Red Teaming.

🛠️ التطبيق العملي: إنتاج Domain Controller افتراضي إضافة مستخدمين وتطبيق سياسة GPO حظر USB.
📖 المصدر الموصى به: TryHackMe - Active Directory Basics أو كورس Heath Adams.
مستوى العمق: Level 2 (Awareness)

ماذا تتعلم: IaaS vs PaaS vs SaaS، نموذج المسؤولية المشتركة (Shared Responsibility Model)، وأساسيات IAM S3.

صلتها بالأمن السيبراني: التمكن من التعامل مع المكونات المعاصرة المستضافة في السحابة وتجنب الثغرات المفتوحة.

🛠️ التطبيق العملي: إنتاج حساب AWS Free Tier واستضافة سيرفر EC2 وتأمين Security Groups.
📖 المصدر الموصى به: AWS Cloud Practitioner Essentials.
🚫 لا تحتاج للتعمق في هذا الآن:

شهادات RHCE المتقدمة، إدارة سيرفرات Exchange المجمعة، أو إدارة Kubernetes Clusters.

⚠️ أخطاء تعليمية شائعة:

إهمال Active Directory وافتراض أن الأمن السيبراني يقتصر على أنظمة Linux فقط!

🎯 معيار الجاهزية للانتقال:

أنت جاهز عندما تنشئ نطاق AD مع بيئة Linux متصلة وتتحكم بالصلاحيات بمرونة ودون تعثر.

المرحلة 3

الأتمتة والسكربت البرمجي (Scripting & Automation)

تحويل المهام اليدوية التكرارية إلى سكربتات برمجية سريعة بالذكاء والـ Python.

⏱️ الجهد الزمني المقدر: 70 - 90 ساعة عمل فعلي
🗓️ 10س/أسبوع: 7-9 أسابيع | 15س/أسبوع: 5 أسابيع | 20س/أسبوع: 3.5 أسبوع
🎓 طالب CS: يمكنه إنهاء هذا الجزء في أسبوع واحد من خلال قراءة مكتبات Python الأمنية فقط.
📚 المنهج الدراسي التفصيلي للمرحلة
مستوى العمق: Level 3 (Practical Knowledge)

ماذا تتعلم: المتغيرات، الدوال، التعامل مع الملفات (Logs/CSV)، ومكتبات `requests` و `socket` و `json`.

صلتها بالأمن السيبراني: كتابة أدوات فحص مخصصة، استخراج السجلات، ومكاملة الـ APIs مع منصات الأمن.

🛠️ التطبيق العملي: كتابة Port Scanner بسيط يستكشف المنافذ المفتوحة عبر خادم محلي.
📖 المصدر الموصى به: كتاب Automate the Boring Stuff with Python أو Violent Python.
مستوى العمق: Level 2 (Basic Working)

ماذا تتعلم: أنابيب الأوامر (Pipes)، فحص النصوص بـ `Grep/Awk/Sed` في Bash، ومفاهيم Cmdlets في PowerShell.

صلتها بالأمن السيبراني: الأتمتة المباشرة داخل أنظمة التشغيل، وتجميع البيانات التحليلية بسرعة بدون تثبيت Python.

🛠️ التطبيق العملي: كتابة سكربت Bash يقرأ ملف Access.log ويستخرج أكثر 10 IPs محاولة للدخول.
📖 المصدر الموصى به: Bash Scripting Tutorial على Ryans Tutorials.
مستوى العمق: Level 2 (Basic Working)

ماذا تتعلم: REST APIs (GET/POST)، مفاتيح API Keys، وإدارة الكود والتغيرات باستخدام Git/GitHub.

صلتها بالأمن السيبراني: التفاعل مع VirusTotal API لإرسال الملفات آلياً وفحصها وبناء البورتفوليو الشخصي.

🛠️ التطبيق العملي: سكربت يرسل Hash لملف إلى VirusTotal ويطبع النتيجة بـ JSON.
📖 المصدر الموصى به: Postman API Fundamentals & GitHub Skills.
🚫 لا تحتاج للتعمق في هذا الآن:

تطوير تطبيقات ألعاب، الأطر البرمجية المعقدة كـ Django/React، أو تعلّم Object Oriented Architecture الكاملة.

⚠️ أخطاء تعليمية شائعة:

الانغماس في دراسة البرمجة لأشهر طويلة وتناسي الهدف الأساسي وهو الأتمتة الأمنية للخدمات.

🎯 معيار الجاهزية للانتقال:

أنت جاهز عندما تستطيع كتابة سكربت أوتوماتيكي يتصل بمصدر بيانات ويستخرج المؤشرات بمرونة.

المرحلة 4

المفاهيم والتطبيقات الأمنية (Cybersecurity Common Fundamentals)

تطبيق الضوابط المفاهيمية والأمنية قبل التوجه لقرار التخصص النهائي.

⏱️ الجهد الزمني المقدر: 60 - 80 ساعة عمل فعلي
🗓️ 10س/أسبوع: 6-8 أسابيع | 15س/أسبوع: 4 أسابيع | 20س/أسبوع: 3 أسابيع
📚 المنهج الدراسي التفصيلي للمرحلة
مستوى العمق: Level 3 (Practical)

ماذا تتعلم: السرية والسلامة التوافرية (Confidentiality, Integrity, Availability)، وتحديد الأصول والتهديدات.

صلتها بالأمن السيبراني: المعيار والبوصلة لقياس أي قرار أمني أو تقييم أي ثغرة سيبرانية.

🛠️ التطبيق العملي: إعداد نموذج STRIDE Threat Model لتطبيق متجر إلكتروني بسيط.
📖 المصدر الموصى به: CompTIA Security+ Study Guide Chapter 1.
مستوى العمق: Level 2 (Basic Working)

ماذا تتعلم: التشفير المتماثل (AES) وغير المتماثل (RSA/ECC)، دالة الهاش (SHA-256)، والبنية التحتية PKI.

صلتها بالأمن السيبراني: حماية البيانات أثناء النقل والتخزين وفهم شهادات SSL/TLS.

🛠️ التطبيق العملي: استخدام OpenSSL لتوليد زوج مفاتيح RSA وتشفير وفك تشفير ملف نصي.
📖 المصدر الموصى به: Khan Academy - Cryptography Challenge.
مستوى العمق: Level 3 (Practical)

ماذا تتعلم: الفرق بين المصادقة والترخيص، MFA، OAuth 2.0، SAML، ورمز Access Tokens (JWT).

صلتها بالأمن السيبراني: حماية الوصول ومنع انتحال الشخصيات أو التسلل غير المصرح به.

🛠️ التطبيق العملي: فك وتحليل هيكل JWT Token وفحص ادعاءات الصلاحية (Claims).
📖 المصدر الموصى به: Auth0 Guides & TryHackMe Authentication Rooms.
مستوى العمق: Level 3 (Practical)

ماذا تتعلم: استعلامات SQL، أخطاء OWASP Top 10 المشهورة، وبنية الخادم والعميل Client-Server.

صلتها بالأمن السيبراني: فهم الثغرات الأكثر انتشاراً مثل SQL Injection و XSS للتمكن من حمايتها أو تقييمها.

🛠️ التطبيق العملي: حُضور واستكمال الموديولات الأولى في PortSwigger Web Security Academy.
📖 المصدر الموصى به: PortSwigger Web Security Academy (مجاني كلياً).
🚫 لا تحتاج للتعمق في هذا الآن:

شراء أجهزة أمن مادية مكلفة، تعلّم هندسة استغلال الثغرات الصفرية 0-Day، أو حفظ اللوائح والتشريعات الكاملة.

⚠️ أخطاء تعليمية شائعة:

القفز لـ Burp Suite والتجريب العشوائي بدون فهم بروتوكول HTTP الأساسي واللغة البرمجية للتطبيق.

🎯 معيار الجاهزية للانتقال:

تهانينا! بإتمام هذه المرحلة أنت الآن تمتلك النواة المشتركة (Common Core) وجاهز تماماً لاختيار تخصصك الدقيق.
