Frontend Developer

مطور الواجهات الأمامية

متخصص في بناء واجهات المواقع والتطبيقات وتحويل التصميمات إلى صفحات تفاعلية سهلة الاستخدام ومتوافقة مع الأجهزة المختلفة.

المهام والمسؤوليات

  • بناء صفحات الويب باستخدام HTML.
  • تنسيق واجهات المستخدم باستخدام CSS.
  • إضافة التفاعلات باستخدام JavaScript.
  • تطوير تصميمات متجاوبة مع الشاشات.
  • تحسين الأداء وإمكانية الوصول.
  • ربط واجهات المستخدم بخدمات Backend.
  • اختبار الواجهات وإصلاح الأخطاء.
