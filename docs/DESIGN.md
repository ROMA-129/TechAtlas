# TechAtlas — Design System

## Brand Identity

- **Name:** TechAtlas
- **Tagline:** Explore. Learn. Build. Advance.
- **Personality:** Creative, futuristic, educational, and professional.
- **Concept:** A digital atlas for exploring the world of technology.

## Logo Concept

The logo combines three visual elements:

- Globe: technology and global knowledge.
- Compass: exploration and career direction.
- Digital orbit: connections between technical fields.

## Design Rules

Use CSS variables to maintain theme consistency.

Avoid excessive animation, unnecessary decoration, and visual clutter.

All visual elements should support the educational experience.
